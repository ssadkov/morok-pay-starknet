## Typography — Inter + JetBrains Mono

- **Display + body:** Inter
- **Mono:** JetBrains Mono for balances, addresses, IDs, and code

Wired with `next/font/local` in `app/layout.tsx`. The official variable WOFF2 assets are stored in `app/fonts`, so local and Vercel builds do not depend on Google at build time. CSS variables are mapped to `--font-sans` and `--font-mono`.

## Gradient

One subtle, palette-derived radial gradient is exposed as `--gradient-hero`.

```css
--gradient-hero: radial-gradient(
  90% 100% at 50% 0%,
  color-mix(in oklch, var(--primary) 22%, transparent) 0%,
  transparent 55%
);
```

Use it only as ambient light behind a hero or page header. Do not use gradient text, gradient form controls, or stack multiple gradients on one screen.

## Tone and voice

Use short, direct English. Lead with the action or outcome: pay privately, create a QR, receive USDC. Be confident and specific, but restrained. Technical details belong in supporting copy, not the main CTA.

Avoid hype such as “revolutionary”, “game-changing”, “unleash”, “exclusive”, and “luxury”. Avoid fake urgency, excessive crypto jargon, emojis, and exclamation marks.

> Create one donation QR. Share it anywhere. Receive private USDC through Ready.

## Usage rules

**Do:**

- Use semantic utilities such as `bg-background`, `bg-card`, `text-primary`, and `border-border`.
- Keep primary buttons at least 40 px high and main transaction actions at 48 px.
- Use `font-mono tabular-nums` for changing financial values.
- Test light and dark themes, narrow screens, keyboard focus, and reduced motion.
- Keep animation short and tied to color, shadow, or transform properties.

**Don't:**

- Hardcode component colors when a semantic token exists.
- Use `transition-all`.
- Put body copy over the hero glow without sufficient contrast.
- Add generic crypto-purple, rainbow gradients, glass layers, or neon borders.
- Use more than one visual accent per section.
